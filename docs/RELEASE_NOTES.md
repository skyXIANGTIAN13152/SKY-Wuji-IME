# SKY.无极输入法 1.0.2

本次正式版本从源码重新构建，安装版本号为 `10002`，可直接覆盖升级本项目的 `1.0.0` 和本机升级测试版 `1.0.1-voicefix`。包名与签名沿用原项目；官方同文是独立应用，不会被覆盖。

- 保留 Android 11 及以上的输入法查询声明，解决官方同文在系统限制应用可见性时可能误报“未安装语音输入”的兼容性问题。这项运行时修复已包含在本项目 `1.0.0` 中，本次增加发布回归检查。
- 纳入此前已同步至源码的 More 底栏、剪贴板卡片、横屏排版、符号与语言切换、微信全选兼容修复，详见[修复记录](KEYBOARD_FIXES_2026-10-12.md)。已保存的应用偏好继续保留。
- 构建流程从源码读取版本，自动核对最终安装包的版本、原项目签名与语音查询声明，避免后续更新遗漏修复。
- 升级内置配置时保留用户已修改或从外部目录导入的同名文件，只自动更新仍与上一版内置内容一致的文件；缺失文件照常补入。新增 11 项临时文件回归检查，避免升级覆盖个人主题。
- 继续内置 V6 红白立体主题、雾凇拼音公开词库和离线 wiki；单个 APK 支持 ARM64 / ARMv7。

语音识别仍由另行安装并启用的「说点啥」完成。如果其返回按钮曾固定指向旧同文，请将返回目标调整为 **SKY.无极**，或选择返回上一个输入法。

已完成的此前兼容性验证：在 HONOR 90 Pro 上，测试版覆盖升级、说点啥同版本覆盖安装、手机完整重启后，系统设置搜索框中的麦克风切换与返回均通过；默认输入法与迁移配置保留。此前测试版只修改安装版本元数据，不是本次正式源码构建；本次安装包的构建与验收结果以 Release 附件为准。

发布包不包含个人词库、剪贴板历史、录音、账号或签名私钥。源码和第三方声明见仓库，APK 校验文件随 Release 提供。
