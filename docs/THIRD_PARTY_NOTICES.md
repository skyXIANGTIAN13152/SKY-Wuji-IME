# 第三方组件与素材

- 输入法程序基于 [同文 Trime](https://github.com/osfans/trime) 3.3.12，保留原作者版权声明，遵循 GPL-3.0-or-later。完整源码及构建入口在本仓库，原生组件版本由 Git 子模块固定。
- 内置词库取自公开的 [雾凇拼音](https://github.com/iDvel/rime-ice)，遵循其 GPL-3.0 许可证及所列来源声明。准确版本见 UPSTREAM.json。没有复制任何设备上的用户词频、学习记录或私人短语。
- 红白键帽基于小先生的 Cherry 主题，取自 [rime-pure](https://github.com/SivanLaai/rime-pure)，保留其 [MIT 许可证](licenses/rime-pure-MIT.txt)。空间键的空白底图和 SKY.无极 标记为本项目定制。
- `sky-preview-microphone-v6.ttf` 使用 Segoe UI Symbol 的麦克风字形；原字体版权归其权利人所有。维护者确认已取得该字形和 Cherry 素材在本项目中修改及公开分发所需的授权。此说明不授予第三方超出权利人许可的复用权，仓库 GPL 许可证也不替代第三方素材的独立授权。
- 语音应用 [说点啥 / BiBi Keyboard](https://github.com/BryceWG/BiBi-Keyboard) 是独立项目，未捆绑其程序或模型。麦克风通过 Android 标准输入法切换功能调用已启用的语音输入法。

应用图标为 SKY.无极 原创矢量图形，按本仓库 GPL-3.0-or-later 许可提供。
